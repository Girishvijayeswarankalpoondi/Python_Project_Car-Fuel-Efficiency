# Python_Project_Car-Fuel-Efficiency
A python code that takes various inputs from the user regarding the Car Model, Fuel, Passenger and Luggage capacity among other factors to analytically deduce the specific fuel consumption rate for given conditions

# Car Fuel Efficiency and Driving Range Estimation
## Requirements
- Python 3.x
- Matplotlib

Install the required library:

```bash
pip install matplotlib
```

## How to Run

```bash
python python_car_effieciency.py
```

## Instructions
1. Select a vehicle from the displayed database.
2. Enter the initial fuel level and intended travel distance.
3. Provide passenger count, luggage weight, and average speed.
4. Enter driving conditions (City/Highway/Mixed).
5. Enter fuel price and expected driving time.
6. Specify AC usage, vehicle service condition, and road condition.
7. View the calculated fuel efficiency, consumption, driving range, fuel cost, and fuel status.
8. View the graphical comparison of fuel efficiency under different conditions.

## Features
- Built-in database of 35+ vehicle models.
- Fuel efficiency adjustment based on driving conditions.
- Fuel consumption, range, and cost estimation.
- Graphical analysis using Matplotlib.
- Input validation.
- Multiple calculations and temporary result retrieval.

**Note:** Results are theoretical estimates based on predefined adjustment factors. Calculation history is cleared when the program exits.
